## how to use

Go to [this link](https://booleanbunny14.itch.io/beat-frozen) and download the files

Press play once it opens and enjoy!

### run it yourself
1. clone the repo
2. install dependencies (MIDI plugin)
3. press play!

## how we built it
We used Godot and the MIDI plugin. 

Looked at [Shredder tutorial](https://shredder.hackclub.com/guides/godot/conductor) for reference. 

## the process
We went through the tutorial to get familiar with the language, as this is our first project of this type. Once we felt comfortable and had one song down, we added the home screen that lead to multiple song choices.
Manu made all the assets!
